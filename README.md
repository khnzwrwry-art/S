# שיגור — אפליקציית יזמות לבני נוער

אפליקציית ווב שמלמדת בני נוער להקים עסק ראשון.

## מבנה הפרויקט

```
index.html
css/
└── styles.css
js/
├── data.js        # DATA, TEMPLATES, EDITING, GLOSSARY, BASICS, QUIZ, LEGAL, TERMS + עזרים (svg/esc/yt, מעקב התקדמות)
├── feed.js        # פיד קהילתי (claude.use('db'))
├── ai.js          # מנטור AI וכלי יצירת תוכן (claude.use('sample'))
└── views.js       # רינדור כל המסכים וניווט ביניהם
```

## מה יש באפליקציה

- **8 מסלולי עסק** — דרופשיפינג, שיווק שותפים, יצירת תוכן, איקומרס, פרינט און דימנד, פרילנס, ניהול רשתות, קורסים דיגיטליים
- **"מה זה בדיוק"** לכל מסלול — איך מרוויחים, עלות התחלה, שעות בשבוע, הכנסה ריאלית, סיכונים
- **שלבים עם מעקב התקדמות** (נשמר ב-localStorage)
- **מנטור AI** + **כלי יצירת תוכן שיווקי**
- **8 טמפלטים לפרסומות** טרנדיות עם תסריטים
- **מדריך עריכה** + מדריך ויזואלי (SVG) לכל שלב בהפקת סרטון
- **פיד קהילתי** עם חיפוש וסינון לפי סוג עסק
- **שאלון התאמה**, **מילון מונחים**, **חלק משפטי**, **תקנון**

## איך להריץ מקומית

```bash
# פשוט לפתוח בדפדפן
open index.html

# או עם שרת מקומי
python3 -m http.server 8000
```

## איך להמשיך לפתח בקלוד קוד

1. להתקין: `npm install -g @anthropic-ai/claude-code`
2. `cd` לתיקיית הפרויקט ואז להריץ `claude`
3. לבקש שינויים בשפה חופשית, למשל:
   - "תוסיף מסלול עסק חדש: עריכת וידאו ללקוחות"
   - "תחליף את קישורי החיפוש ביוטיוב בקישורים הספציפיים שבקובץ videos.json"

## חשוב לדעת

- **המנטור וכלי התוכן** (`js/ai.js`) עובדים דרך `claude.use('sample')` — זה קיים רק בתוך ארטיפקט של Claude.
  באתר עצמאי צריך להחליף לקריאה ל-API של Anthropic **דרך שרת** (אסור לחשוף מפתח API בצד לקוח).
- **הפיד** (`js/feed.js`) עובד דרך `claude.use('db')`. באתר עצמאי צריך להחליף ל-Firebase / Supabase.
- **הסרטונים** הם כרגע קישורי חיפוש ביוטיוב. להחלפה בקישורים ספציפיים: לערוך את שדה `video` בכל שלב ב-`DATA` (בקובץ `js/data.js`).
- **התקנון** (`TERMS` ב-`js/data.js`) הוא טיוטת בסיס בלבד וצריך בדיקה של עורך דין לפני עלייה לאוויר.
